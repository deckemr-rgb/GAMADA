# GAMADA — illustration assets

All illustrations are **original layered SVG sources** in `src-art/scenes/<scene>/<layer>.svg`. `npm run art` optimises them with svgo and rasterises them into trimmed AVIF/WebP variants (1280/1920/2560 canvas widths) in `public/scenes/`. The variants are listed in `src/lib/layers.generated.json`. To swap in painted art, drop a PNG on the **same canvas** in place of the SVG (or extend the build script to accept PNG) and re-run `npm run art`. The runtime code does not change.

## Canvas and conventions

| | |
|---|---|
| Canvas per layer | **2560 × 2304 px**: a 16:9 frame of 2560 × 1440 plus **30 % bleed** (432 px) above and below |
| Visible frame | `y ∈ [432, 1872]` at 16:9. Taller or narrower screens crop horizontally around `focusX` |
| Rendering | `object-fit: cover; object-position: focusX 50%` in a layer box of 106 % × 160 % of the viewport (3 % overscan for pointer parallax, 30 % bleed for scroll parallax) |
| Alignment | all layers of one scene share the canvas, so they line up exactly when stacked |
| Full-bleed layers | sky / backdrop fill the **entire** canvas. Ground and foreground layers extend to `y = 2304` so transitions never reveal a gap |
| Transparency | everything except sky/backdrop is transparent around its subject |
| Bridges | `public/scenes/bridges/<from>-<to>.svg`, same canvas, with the **opaque band centred on y = 1152** (core about 950–1400) and mist fading out about 300 px above and below. The band rides the seam between two scenes |
| Live layers | waterfalls (`WATERFALLS` rects), god rays (`GODRAYS` origins) and flocks are drawn by code. Their geometry is defined in canvas coordinates in `assets.ts` |
| Formats | Sources: SVG. Runtime: AVIF (primary) + WebP (fallback). Each layer is trimmed to its alpha bbox and served via `<picture>`/`srcset`, with phones pinned to the 1280 variant. Totals: desktop 892 KB · laptop 791 KB · mobile 397 KB |
| Image-generation style | *painterly anime landscape, Japanese countryside, dusk palette violet-orange, soft cel shading, transparent background, isolated layer, 2560x2304 canvas with 30% bleed top and bottom* |

### Depth → motion

`depth` (0 = farthest … 1 = nearest) drives everything:
- scroll parallax `k = lerp(0.3, 1.4, depth)`
- dolly zoom `1 → lerp(1.06, 1.18, depth)`
- pointer parallax `depth × 30 px`
- depth-of-field blur on layers flagged `dof`

Layers flagged `wind` sway from their bottom edge. `sway` layers rotate around a canvas pivot (the scarf at 2080, 1395). `pose` layers cross-fade within a group (the deer).

### Copy-safe zones (16:9 canvas coordinates)

| Scene | Copy side | Zone |
|---|---|---|
| hero | left | x 0–1150, y 600–1550 |
| tranquility | right | x 1500–2420, y 650–1450 |
| biodiversity | left | x 0–1150, y 650–1450 |

Keep these areas calm and darker so the copy stays AA-readable. A scrim gradient is also applied in CSS.

### Regenerating the art

The `.svg` files in `src-art/scenes/` are the source of truth. The seeded generator scripts used to draft them were temporary. Run `npm run art` to optimise the sources with svgo and regenerate `public/scenes/*.avif|webp` plus `src/lib/layers.generated.json`. Animated parts are separate layers: the scarf (pivot 1852, 1404), the elder's rod (pivot 831, 1286) and the turtle head (pivot 1160, 1682) sway in code, and the three deer poses cross-fade.

A hidden grotto at dusk turning to night. Deep violet-blue and indigo, with cyan light falling through a skylight in the cave roof.
